R&M CATASTRALES — WEB
======================

Versión reorganizada de la web de R&M Catastrales.

Contenido y navegación:
- Inicio: portada exclusivamente.
- Empresa: presentación y forma de trabajo exclusivamente.
- Servicios: catálogo de servicios catastrales exclusivamente.
- Trabajos de campo: comprobación y toma de datos en inmuebles, con su documentación gráfica.
- Callejero: contenido específico de actualización y mantenimiento del callejero municipal.
- Contratación pública: administraciones, entidades y experiencia acreditada.
- Sede Electrónica del Catastro: enlace oficial externo.
- Envío de documentación: formulario de aportación de documentación.
- Contacto: datos de contacto.

Cada opción del menú se comporta como una página independiente: al acceder a una sección solo se muestra el contenido correspondiente a esa sección. Se evita así la repetición de Trabajos de campo, Administraciones, Experiencia, Sede Electrónica, Envío de documentación, Contacto y otros contenidos en páginas que no les corresponden.

Para usarla:
1. Descomprime el ZIP.
2. Abre index.html en un navegador.
3. Para publicarla, sube todos los archivos y la carpeta assets al alojamiento web.

Nota:
El alcance concreto de cada servicio depende del contrato y del marco de colaboración aplicable.
